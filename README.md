# Festival Access & Crowd Control System

## Project Description

This project is a JavaScript program that manages festival entry and attendees. It checks tickets and age, assigns wristbands, calculates food vouchers, tracks spending, and controls venue capacity.

## Technologies Used

- JavaScript
- Node.js

## How to Run

1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `node index.js`.

## Features

- Attendee queue management
- Entry and VIP access checks
- Food voucher rewards
- Festival statistics
- Biggest spender detection
- Venue capacity control
- Closing-time countdown
- Festival control dashboard

## Concepts Practised

Variables, arrays, objects, loops, conditional statements, switch statements, `break`, and `continue`.
